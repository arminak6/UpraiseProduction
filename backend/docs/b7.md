# B7 - Delete generated teaching content

`DELETE /v1/lesson-jobs/{lesson_job_id}?learner_level=intermediate`

| Input | Meaning |
|---|---|
| `lesson_job_id` | Required generated lesson job UUID, as listed by A8. A7 processing IDs are not accepted. |
| `learner_level` | Optional existing level name. Omit to delete all generated levels of this lesson. |
| Body | None. |

Requires authentication as the lesson's client and access to its course.
Success: **204 No Content**, empty body, after content and artifact cleanup.
Deleting the last remaining level also deletes the whole generated lesson.
Ingested source documents, Qdrant vectors and other generated lessons remain.
New A3 generation may use the preserved documents with a fresh idempotency key.
B3/B6 remain reserved; B7 is the user-approved generated-content extension.

## Flow

1. Validate client ownership and course access, job UUID and level. Commit a durable deletion
   operation and level tombstone; whole deletion also revokes job ownership.
2. Fence and clean unpublished A7 requests targeting that level or all levels.
   An unrelated single-level revision may continue after cleanup. Whole deletion
   cancels initial generation too; selected-level deletion during initial
   QUEUED/RUNNING generation returns409 instead of publishing a partial bundle.
3. For available multi-level output, prepare an integrity-checked manifest and
   audio directory containing only remaining levels. One PostgreSQL transaction
   deletes the selected retained text/SSML and switches the artifact pointer/hash
   and level/count summary. Other chunks, voices, IDs and expiry are unchanged;
   the shared plan remains while a level is retained. A7 all-level requests then
   cover only the remaining available levels.
4. Remove old manifests/audio/checkpoints and affected revision candidates.
   Whole deletion also removes the shared plan and scrubs embedded content from
   job metadata. Operational IDs and content-free audit remain. Expired or A6-
   acknowledged output still permits deletion of its permanently retained text;
   deletion never revives expired audio or extends its TTL.
5. Record a content-free event keyed by the deletion UUID, mark cleanup complete
   and return204. Repeating the same request resumes cleanup or returns204 without
   duplicate deletion audit. Lesson delivery/listing is unavailable while cleanup
   is pending; deleted-level A5 access and old audio URLs return404 afterward.

`lesson_content_deletions` stores only identifiers, scope, artifact UUIDs and
timestamps. Lesson-delivery maintenance recovers incomplete operations after an
outage/restart. Pending operations block new A7 snapshots and publication; stale
requests cannot restore a deleted level. The full result hash changes, so bound
B1/B2/B4 sessions are invalidated (including sessions on retained levels). New
playback uses the updated manifest and requires fresh approval/session binding.
A6 on a processing ID preserves current B7-owned artifacts. A2 source/course
deletion also removes directories created by B7.

## Errors

| HTTP | Meaning |
|---|---|
| 401/403 | Authentication or course access denied. |
| 404 | Unknown/inaccessible lesson, unknown level, or source-deleted lesson. |
| 409 | A7 processing ID supplied, or selected-level deletion requested while initial generation is queued/running. |
| 422 | Invalid UUID or level syntax (lowercase identifier, maximum40 characters). |
| 503 | Cleanup/storage/audit/lock pending or unavailable. Retry the same DELETE; server recovery also runs automatically. |

## UI

**Delete teaching content (B7)** lists prepared lessons and permits manual job ID
and level entry for retained expired content. Selected level is the default;
**All generated levels** is explicit. Changing job/scope/level resets confirmation.
Deleting and retrying require explicit clicks; no DELETE is automatic. A503 pins
the original job/scope for manual retry across navigation. Success refreshes the
list and clears cached generated text/audio/player/revision context. Source lists
are preserved. A5 workspace and A7 views link to this page with the selected
lesson/level; prefills and pending requests are bound to connection credentials.
