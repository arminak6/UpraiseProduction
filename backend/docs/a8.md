# A8 - List ready generated lessons

The user approved A8 on 2026-10-07 to let the frontend discover lessons already
generated through A3, including jobs submitted through curl. This is an extension
to the original Word baseline; A7 remains reserved for audio regeneration.

`GET /v1/lesson-jobs` returns a JSON array of lesson summaries. It does not generate
content, return lesson text, open learner sessions or acknowledge receipt.

## Input and access

Normal authoring OAuth/mTLS INGRESS and `jobs:read` apply. Results belong to the
authenticated client and are restricted to its authorized courses. Optional query
parameters:

| Parameter | Default | Constraint |
| --- | --- | --- |
| `course_id` | All authorized courses | Nonempty, at most 120 characters; requires course access |
| `limit` | 100 | 1 through 100 |
| `offset` | 0 | 0 through 1,000,000 |

Filtering happens before pagination. Results are ordered newest first by creation
time, then job UUID. An empty result is `200 []`. Missing scope or an explicitly
unauthorized course is 403; invalid parameters are 422; unavailable storage is 503.
Responses use `Cache-Control: no-store`.

## Output and availability

Each summary contains `job_id`, `lesson_id`, `course_id`, `activity_id`, `language`,
`voice`, `learner_level`, `chunk_count`, `status`, `label`, `requires_review`,
`review_issue_count`, `created_at` and `expires_at`.

Only DONE jobs with unexpired output, no requested cleanup, and active, undeleted
DONE source documents belonging to the same client/course are listed. Lesson
status remains DRAFT and requires human review; ready means ready for preview,
not approved teaching content. Failed, running, cancelled, expired and acknowledged
jobs are excluded. Duplicate lesson IDs from separate generations have distinct
job IDs and creation times.

A5 remains authoritative when opening a lesson: it rechecks access, source
activation, artifact integrity and audit availability. A job can become unavailable
between listing and playback, or an artifact can be missing/corrupt. The frontend
handles those failures and offers another selection or retry.

## Frontend use and retention

The Learning page calls A8 for its selector, A5 result for ordered text, and A5
audio for one part at a time. Start, Previous, Next, Replay and Restart recheck A5.
The browser audio controls pause/resume. Progress is held only in the Streamlit
session; backend APIs remain the only content access path. No direct database or
AWS access is added to the frontend.

The default A5 retention remains 24 hours. A8 does not extend it or recover audio
from expired jobs. PostgreSQL retains finalized text/SSML, but there is currently
no archive playback API. Playback does not send A6 automatically.

## One-line PowerShell curl

```powershell
curl.exe -i "http://localhost:8000/v1/lesson-jobs?course_id=test-course&limit=100&offset=0"
```

Use normal OAuth and the mTLS gateway outside explicit development local-test mode.
