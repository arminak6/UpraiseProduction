# A5 - Download a job result (pull mode)

A5 reads temporary A3 output. It does not generate a lesson or call Bedrock/Polly.
Use it when Middleware pulls the result rather than receiving its JSON through
an optional callback.

## Endpoints

| Method and path | Input | Output |
| --- | --- | --- |
| GET /v1/jobs/{job_id}/result | Job UUID | The complete A3 LessonResult JSON |
| GET /v1/jobs/{job_id}/audio/{chunk_id} | Job UUID and that job's chunk UUID | One audio/wav file |

The JSON keeps the existing A3 contract: lesson/course/activity IDs, DRAFT status,
ordered text chunks, SSML, audio URLs/hashes/durations, visemes, provenance,
review reports, versions and expires_at. No new generation input is required.

## Flow

1. INGRESS validates the normal OAuth/mTLS authoring credentials and jobs:read
   scope. The caller must own the job and have access to its course.
2. The orchestrator checks DONE state, output expiry, source activation and
   artifact integrity, then reads temporary JSON or opens the requested WAV.
3. AUDIT records a distinct RESULT_ACCESSED or AUDIO_ACCESSED event before
   delivery. Only IDs, hashes, mode and audio byte count are stored.

Audit failure returns 503 AUDIT_STORAGE_UNAVAILABLE without serving the artifact.
An access event means that serving was authorized and prepared; it does not prove
that the client received every byte, or acknowledge A6 receipt.

Readers use shared file locks, so simultaneous result/audio requests can proceed.
Generation and cleanup retain exclusive locks. An actual writer/cleanup conflict
can return 503 JOB_CLEANUP_PENDING with Retry-After: 2. Audio opens under the lock,
then streams without holding it for the entire transfer; handles are closed on
completion, interruption or failure.

## TTL and status responses

TTL defaults to 24 hours after job completion and is configurable through
UPRAISE_LESSON_TTL_SECONDS. Both endpoints reject new requests at expiry, even
before physical deletion. The independent delivery worker deletes expired
lesson output; source PDFs, vectors and operational history remain.
The finalized text/SSML archive in PostgreSQL also remains, per the 2026-10-06
storage decision. These endpoints still return 410 after disposal/expiry; they
do not read the durable archive or regenerate audio.
The archive has no automatic TTL. Explicit A2 document/course deletion removes
the corresponding generated text, SSML and plans across all levels/languages.

| Status | Meaning |
| --- | --- |
| 200 | Result JSON or requested WAV is available |
| 403 | Missing jobs:read scope |
| 404 | Unknown/inaccessible job or a chunk that does not belong to it |
| 409 | Output is not ready, or its source is no longer available |
| 410 | Output expired or was disposed through A6 |
| 422 | Malformed UUID |
| 503 | Storage/audit unavailable, integrity failure, or an active writer lock |

Responses use Cache-Control: no-store. WAV responses include Content-Length,
Content-Disposition and an ETag containing the audio SHA-256.

Pulling output never marks the lesson approved, acknowledges receipt, or extends
TTL. Middleware stores the JSON and all needed WAV files, then explicitly calls
DELETE /v1/jobs/{job_id}?reason=RECEIVED through A6. That removes temporary lesson
artifacts. It does not delete source material.

No callback configuration is needed for A5. If A3 pushes its JSON to Middleware,
the JSON GET is optional; audio URLs still refer to these WAV endpoints until A6
receipt or expiry. A callback 2xx does not dispose output automatically.

## PowerShell local test

With explicit development local_test_mode enabled, download the user's completed
job without submitting another paid generation:

~~~powershell
$result = Invoke-RestMethod 'http://localhost:8000/v1/jobs/241c4bda-3cc8-4ffd-a029-48bed27070a1/result'
~~~

Download its first chunk using the URL returned in that JSON:

~~~powershell
Invoke-WebRequest -Uri ('http://localhost:8000' + $result.chunks[0].audio_url) -OutFile 'lesson-chunk-0.wav'
~~~

To save JSON too:

~~~powershell
$result | ConvertTo-Json -Depth 100 | Set-Content -Encoding UTF8 'lesson-result.json'
~~~

These example IDs remain valid only until the job's expires_at or A6 disposal.
Production uses the normal OAuth token and client certificate at the AI gateway.

## Verification

test_a5_integration.py covers per-request audit, parallel JSON/audio reads,
expiry and physical cleanup, scope/client/course isolation, corrupt artifacts,
unknown chunks and audit outages. test_artifact_locks.py verifies shared readers,
exclusive writers and release after a process crash on Windows and Linux.
